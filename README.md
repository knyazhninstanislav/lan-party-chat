## 📖 О проекте

**LAN Party** - это лёгкий веб-чат, работающий **по локальной сети** без интернета и внешних зависимостей. Каждое сообщение — это отдельная **заявка** (тикет) с возможностью:

- 📝 писать многострочные сообщения;
- 📎 прикреплять файлы (документы, архивы, видео, аудио);
- 🖼️ вставлять скриншоты через `Ctrl+V` или drag-and-drop;
- ↩️ отвечать на конкретные заявки;
- ✏️ редактировать и 🗑️ удалять свои сообщения;
- ✅ помечать заявки как **выполненные**;
- 😊 вставлять эмодзи;
- 🔔 получать уведомления о новых заявках;
- 👀 видеть статус прочтения (`✅ прочитано N раз`).

Сервер написан на **чистом Python** (стандартная библиотека), клиент — на **ванильном JavaScript**. Никаких фреймворков, сборщиков и `npm install`.

## 🚀 Быстрый старт

### Требования

- **Python 3.7+** (используется только стандартная библиотека)
- Любой современный браузер
- Все устройства — **в одной локальной сети**

### Запуск сервера

```bash
python server.py
```

Сервер сам найдёт свободный порт в диапазоне `5000–5100` и напишет в консоль:

```
🔍 Используется порт: 5000
==================================================
🚀 Тикет-система запущена!
📱 Откройте в браузере: http://localhost:5000
==================================================
```

### Доступ с других устройств

1. Узнайте IP-адрес хоста:

   **Windows:**
   ```bash
   ipconfig
   ```
   Смотрите строку `IPv4-адрес` в активном подключении.

   **Linux / macOS:**
   ```bash
   ip addr
   # или
   ifconfig
   ```

2. На других устройствах откройте:

   ```
   http://<IP-хоста>:5000
   ```

   Например: `http://192.168.1.42:5000`

### Остановка

Нажмите `Ctrl+C` в терминале, где запущен сервер.

## 🔌 API — краткая справка

Все эндпоинты принимают и возвращают **JSON**.

### `GET` запросы

| Метод | Путь | Описание |
|---|---|---|
| `GET` | `/` | HTML-страница чата |
| `GET` | `/style.css` | Стили |
| `GET` | `/main.js` | Клиентский скрипт |
| `GET` | `/api/messages` | Список сообщений (с вложениями и `read_count`) |
| `GET` | `/api/users` | Активные пользователи (last_seen < 15 сек) |
| `GET` | `/api/attachment/<id>` | Скачать/открыть вложение по ID |

### `POST` запросы

| Метод | Путь | Тело | Описание |
|---|---|---|---|
| `POST` | `/api/send` | `{username, user_id, message, attachments[], reply_to?}` | Отправить новую заявку |
| `POST` | `/api/edit` | `{message_id, message, username}` | Редактировать своё сообщение |
| `POST` | `/api/delete` | `{message_id, username}` | Удалить своё сообщение |
| `POST` | `/api/toggle_completed` | `{message_id, username}` | Переключить статус «Выполнено» |
| `POST` | `/api/mark_read` | `{message_id, user_id}` | Отметить сообщение прочитанным |
| `POST` | `/api/users` | `{username, user_id?}` | Регистрация/вход |
| `POST` | `/api/heartbeat` | `{user_id}` | Продлить сессию (онлайн) |
| `POST` | `/api/logout` | `{user_id, username}` | Выход |

## 🗄️ База данных

SQLite, файл `chat.db` создаётся автоматически при первом запуске.

### Таблицы

**`users`** — пользователи

| Поле | Тип | Описание |
|---|---|---|
| `user_id` | TEXT (PK) | Уникальный ID |
| `username` | TEXT | Отображаемое имя |
| `last_seen` | REAL | Timestamp последней активности |
| `created_at` | REAL | Дата регистрации |

**`messages`** — сообщения-заявки

| Поле | Тип | Описание |
|---|---|---|
| `id` | TEXT (PK) | Уникальный ID |
| `username` | TEXT | Автор |
| `user_id` | TEXT | FK на `users` |
| `message` | TEXT | Текст заявки |
| `timestamp` | TEXT | Время (`HH:MM:SS`) |
| `edited` | INTEGER | `1`, если редактировалось |
| `edit_time` | TEXT | Время правки |
| `reply_to` | TEXT | ID родительского сообщения |
| `completed` | INTEGER | `1`, если выполнено |
| `created_at` | REAL | Timestamp создания |

**`attachments`** — вложения

| Поле | Тип | Описание |
|---|---|---|
| `id` | INTEGER (PK) | ID файла |
| `message_id` | TEXT | FK на `messages` (CASCADE) |
| `filename` | TEXT | Имя файла |
| `file_data` | TEXT | Содержимое в base64 |
| `file_type` | TEXT | MIME-тип |
| `file_size` | INTEGER | Размер в байтах |

**`read_receipts`** — прочтения

| Поле | Тип | Описание |
|---|---|---|
| `message_id` | TEXT | FK на `messages` |
| `user_id` | TEXT | FK на `users` |
| `read_at` | REAL | Timestamp |

### Сброс БД

Просто удалите chat.db

## 🧭 Как пользоваться

1. **Вход** — введите имя в поле сверху и нажмите «Войти».
2. **Создание заявки** — напишите текст, при необходимости прикрепите файлы, нажмите «Создать» (или `Enter`).
3. **Многострочный текст** — `Shift+Enter`.
4. **Ответ на заявку** — нажмите «Ответить» под нужной карточкой.
5. **Отметить выполненной** — зелёная галочка ✅ «Выполнено».
6. **Редактирование/удаление** — доступно только автору.
7. **Вставка скриншота** — `Ctrl+V` прямо в поле ввода.
8. **Выход** — кнопка «Выйти» в правом верхнем углу.

## 🔧 Решение проблем

### Порт занят

Сервер сам подберёт свободный в порту диапазоне `5000–5100`. Если нужно зафиксировать — измените в `server.py`:

```python
PORT = 5000  # вместо find_free_port()
```

### Другие устройства не подключаются

- Убедитесь, что все в одной сети.
- Проверьте фаервол — разрешите входящие на порт `5000` (или тот, что выбран).
- Windows: добавьте правило в «Брандмауэр Защитника».

### Не отображаются картинки/файлы

- Файлы хранятся в БД в base64 — большие вложения могут замедлить загрузку.
- Уменьшите `MAX_FILE_SIZE` или используйте файловое хранилище.

### «Сессия истекла»

- Пользователь удаляется из БД при выходе или если `last_seen` старше 15 секунд.
- Обновите страницу и войдите заново.
